# CQC Marketing

A modern, responsive landing page for **CQC Marketing**, a social media marketing studio helping brands grow their online presence.

## Features

- Responsive design for desktop, tablet, and mobile
- Modern hero section and navigation
- Social media marketing services
- Step-by-step work process
- Featured creative concepts and portfolio showcase
- FAQ accordion
- Contact form with client-side validation
- Mobile navigation menu
- Accessibility and reduced-motion support

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Lucide Icons
- Google Fonts — Manrope

## Project Structure

```text
cqc-marketing/

```

## Run Locally

1. Download or clone this repository.
2. Keep all project files in the same folder.
3. Open `index.html` in your browser.
4. For a better development experience, use Visual Studio Code with Live Server.

## Deployment

This website can be deployed using Netlify.

1. Push the project files to GitHub.
2. Log in to Netlify.
3. Import your GitHub repository.
4. Set the publish directory to the project root.
5. Deploy the website and test the live URL.

## Before Launch

- Update business contact details.
- Add real social media profile links.
- Replace placeholder testimonials and sample projects.
- Configure the contact form with a working backend or form service.
- Add a proper privacy policy.
- Test the website on mobile and desktop.

**Note:** The contact form is not connected to a backend by default, so messages will not be delivered until it is configured.
